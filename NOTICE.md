# Notice

**English** | [Português (Brasil)](NOTICE.pt-BR.md)

`VERTIV by SNMP` is a community-maintained Zabbix template for monitoring Vertiv/Liebert UPS systems by SNMP.

## Attribution

The project was created with the following template as a structural and historical reference:

- **Template Vertiv**
- Original author: **Mihguel da Silva Santos Tavares de Araujo**
- Original source: https://github.com/Mihguel-Araujo/Template-Zabbix/blob/main/Template%20Vertiv

The referenced repository was reviewed on 2026-09-10. At that time, its root contained the template files but no `LICENSE` file, and no explicit license notice was found in the referenced template. For that reason, this repository does **not** redistribute the original template file or claim to relicense it.

This repository's maintained template was substantially rewritten for UPS monitoring using RFC 1628 UPS-MIB objects and Vertiv/Liebert enterprise OIDs, with new keys, triggers, value maps, macros, discovery rules, documentation, validation tooling, and repository organization.
